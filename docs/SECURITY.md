# 部署和数据安全

## 数据位置

网页默认 `./data`，可用 `SUBTITLE_DATA_DIR` 指定。桌面使用 Electron 的 `userData/workspace`（Windows 通常在 `%APPDATA%` 下）；安卓使用应用私有目录，禁止系统备份。三个版本互不自动同步。

SQLite 保存项目、历史字幕、任务快照和远端 ID。上传视频、抽取的音频和成片保存在同一数据根目录下。任务失败时保留诊断所需文件；当前没有自动删除项目的界面，请在停止所有处理进程后管理备份及磁盘空间。

## 凭据

- 服务器：AES-256-GCM；使用 `SUBTITLE_MASTER_KEY` 的 64 位十六进制值。开发时可自动生成数据目录中的 `.masterkey`。正式部署应从安全的环境配置提供主密钥。
- 桌面：随机主密钥由操作系统保护，不能直接把加密凭据搬到另一台电脑使用。
- 安卓：Android Keystore 中不可导出的 AES 密钥。卸载应用将清除本机项目和凭据。
- 供应商列表只返回已填写字段名，不回传密钥；编辑时留空表示保留旧值。日志不打印请求鉴权头。

这是单管理员共享空间。所有能登录的人均可查看、修改全部项目及模型配置，不提供项目级访问隔离。

## 网络边界

原视频不主动上传至模型厂商。识别时发送所选供应商所需的音频分片；翻译时发送字幕、上下文及术语。它们仍然可能包含隐私，应先确认厂商的数据政策。

默认只访问 HTTPS 公网地址，限制重定向，检查 DNS 解析与实际连接地址。管理员勾选“允许内网”后，该配置可访问 HTTP/私有网络，必须信任相应服务。安卓允许原生 HTTP 的前提也由该配置检查；WebView 的 CSP 不允许任意外部连接。

网页使用 scrypt 密码散列、HttpOnly/SameSite Cookie、同源校验、请求限流、上传偏移和 SHA-256 分块校验。上传大小上限 30 GB，单块上限 8 MB；界面发送 4 MB 分块。媒体目录经真实路径校验，挂载目录只读。FFmpeg/ffprobe 限制网络协议与允许探测的容器类型。

这些措施不是完整安全审计。请置于可信网络或 HTTPS 反向代理后，保持 Node、Electron、FFmpeg 和依赖更新。不支持公网多租户服务。

## 临时对象和恢复

URL 型 ASR 只暂存音频，签名 URL 有效期为 48 小时；临时会话凭据可能更早失效。S3/OSS/COS/GCS 桶应设置 `subtitle/` 前缀的短期生命周期清理，以覆盖应用长期关闭或凭据被删除等情况。

Node worker 在成功后删除远端暂存音频；失败/取消的对象在处理窗口结束后重试清理。安卓成功任务会清理音频；中断后依赖恢复处理和桶生命周期保底。远端任务本身无法保证取消计费。

提交状态不明时不会自动重发；确认重试可能再次收费。不能保证请求发出和远端任务 ID 写入本地之间实现分布式“恰好一次”。

## 备份

停下 web/worker 或桌面应用后，完整备份数据目录与主密钥；不要只复制一个正在写入的 SQLite 主文件而漏掉 WAL。恢复后先核对媒体路径、字体、供应商凭据和任务状态。服务器主密钥、桌面系统密钥、安卓 Keystore 不能互换。
